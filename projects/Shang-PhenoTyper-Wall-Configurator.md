# PhenoTyper Wall Configurator

## 功能描述

PhenoTyper PT3000 的四面墙板可以根据实验需求进行组合，例如饮水墙、饲料墙、Shelter 墙、带门墙、跑轮墙和 Cognition Wall。表面上这些墙板可以“自由组合”，但实际上，不同墙板两端的连接结构、安装方向和功能部件并不完全相同，同一块墙板放在不同位置时，也可能产生不同的兼容结果。

公司过去曾在官网提供一款 **PhenoTyper Wall Configurator**，用于帮助销售、技术人员和客户检查四面墙板能否正确安装。随着官网调整，原工具已经无法使用，但在售前选型、报价确认、客户改装和技术支持过程中，这一需求仍然存在。

本项目计划重新开发一个轻量化的网页配置工具。用户可以分别选择 PhenoTyper 的上、右、左、下四面墙板，系统根据预先整理的兼容规则，实时检查四个墙角的连接状态：

- 兼容时显示绿色对勾；
- 不兼容时显示红色叉号；
- 尚未录入规则的组合显示“待技术确认”。

该工具解决的主要问题包括：

1. 避免仅凭经验判断墙板组合，降低选型和下单错误；
2. 帮助销售人员在报价前快速确认配置可行性；
3. 帮助技术人员远程指导客户更换或重新组合墙板；
4. 将分散在旧网页、历史订单和人员经验中的产品知识整理为可维护的规则库；
5. 为新员工提供直观的 PhenoTyper 产品学习工具。

第一阶段仅针对使用需求较多的 **PT3000 小鼠笼体**，暂不包含 PT4500 大鼠笼体。

## 核心 Prompt

```text
请使用 HTML、CSS 和原生 JavaScript，开发一个名为
“PhenoTyper Wall Configurator”的单页面网页工具。

项目背景：
PhenoTyper PT3000 小鼠笼体由四面可更换墙板组成。不同墙板具有特定的连接方向和兼容关系，并非所有组合都可以实际安装。

页面要求：

1. 页面中央显示一个 PhenoTyper 笼体的俯视示意图；
2. 在示意图的上、右、左、下分别放置四个墙板选择器；
3. 四个位置编号为：
   - 0：上方
   - 1：右侧
   - 2：左侧
   - 3：下方
4. 每个选择器显示墙板缩略图、产品名称和 SKU；
5. 用户切换任意墙板后，系统立即重新检查四个墙角：
   - 左上角：位置 0 与位置 2
   - 右上角：位置 0 与位置 1
   - 左下角：位置 2 与位置 3
   - 右下角：位置 1 与位置 3
6. 兼容时显示绿色对勾；
7. 不兼容时显示红色叉号；
8. 规则库中没有记录时显示灰色问号，并提示“需要技术确认”；
9. 所有墙板资料和兼容规则必须集中保存在独立的数据结构中，不要使用大量写死的 if/else；
10. 未经确认的产品规则不得由 AI 自行推测，应在代码中标记为 TODO；
11. 页面采用白色背景、浅灰色边框和简洁的工程工具风格；
12. 网页应能够直接在浏览器中运行，不依赖服务器或大型前端框架。

请先搭建可运行的页面框架和示例数据，后续再逐步补充真实墙板图片、SKU 和兼容规则。
```

## 演示素材

### 历史参考截图

目前已经找到原版 PhenoTyper Wall Configurator 的历史截图，可用于展示：

- 四面墙板的选择方式；
- 四个墙角均兼容的配置；
- 单个墙角不兼容的配置；
- 两个墙角同时不兼容的配置；
- Cognition Wall 调整方向后兼容结果发生变化的情况。

### 新版演示素材

完成第一版网页后，将补充以下内容：

1. 新版配置器首页截图；
2. 四角全部兼容的配置截图；
3. 墙板方向冲突的配置截图；
4. 切换墙板后实时更新结果的短视频或 GIF；
5. 当前配置结果的导出示例。

演示过程建议控制在 30–60 秒：

1. 打开配置器；
2. 选择四块兼容墙板；
3. 展示四个绿色对勾；
4. 调换一块功能墙的位置；
5. 展示对应墙角变为红色叉号；
6. 再次调整墙板，使配置恢复为可行状态。
