# Biopac 配置方案导出工具

> 队伍：Operation　|　成员：2 人

## 功能描述

Biopac（BIOPAC Systems）的生理信号采集系统采用模块化架构：以 MP160 / MP150 数据采集主机为核心，配合 ECG、EMG、EEG、RSP、PPG、GSR、EOG 等各类放大器模块与对应传感器、AcqKnowledge 软件共同组成一套完整的实验系统。一套配置往往包含主机、若干放大器、多个传感器、转接件与软件授权，组件之间的搭配关系、通道数量、与第三方设备（如 Noldus 行为观测系统）的同步方案都需要仔细核对。

目前的配置流程主要依赖销售/技术人员的经验或逐项翻阅产品手册，存在几个痛点：

1. 选型时容易漏配转接件、同步模块或软件授权，导致到货后无法立即开展实验；
2. 配置单以 Excel 手工填写为主，格式不统一，传递给客户或内部流转时易出错；
3. 新员工缺乏对 Biopac 模块体系的整体认识，上手周期长；
4. 历史配置方案散落在各人电脑与旧报价单中，难以复用与检索。

**Biopac 配置方案导出工具**旨在解决上述问题。用户在网页上按实验需求选择所需的 Biopac 模块（主机、放大器、传感器、软件等），系统根据预先整理的产品资料与搭配规则，实时校验配置合理性，并可一键导出标准化的配置单（支持 PDF / Excel / 纯文本多种格式）。

核心功能包括：

- 可视化模块选择界面，按类别陈列 Biopac 各类模块及其缩略图、型号、关键参数；
- 选配时的合理性提示（如通道数超限、缺少必需转接件、软件授权与采集通道不匹配等）；
- 自动汇总配置清单，包含型号、数量、单价区间与用途说明；
- 一键导出标准化配置单，便于发给客户或归档；
- 常用配置方案保存与复用，将分散经验沉淀为可检索的方案库。

第一阶段聚焦 **MP160 系统**及常用放大器、传感器组合，后续可逐步扩展至 MP150 旧系统与更多细分模块。

## 核心 Prompt

> 以下为引导 AI 实现本工具的代表性提示词。完整协作过程中包含多轮迭代，此处摘录关键片段。

```text
请使用 HTML、CSS 和原生 JavaScript，开发一个名为
“Biopac 配置方案导出工具”的单页面网页工具。

项目背景：
Biopac 生理信号采集系统由数据采集主机（MP160）、各类放大器模块
（ECG/EMG/EEG/RSP/PPG/GSR/EOG 等）、对应传感器、转接件与
AcqKnowledge 软件授权共同组成。一套配置必须保证组件之间可搭配、
通道数不超限、软件授权与采集通道匹配，并常需与 Noldus 行为观测系统
做时间同步。

页面要求：

1. 页面左侧按类别分组陈列可选模块：
   - 数据采集主机
   - 放大器模块
   - 传感器与电极
   - 转接与同步件
   - 软件与授权
2. 每个模块显示缩略图、型号、SKU、关键参数与用途说明；
3. 用户点击模块即加入右侧“当前配置”清单，可调整数量、移除；
4. 任意变更后立即重新校验配置合理性：
   - 主机通道数是否足够容纳所选放大器；
   - 是否缺少必需的转接件或同步模块；
   - 软件授权通道数是否覆盖实际采集通道；
   - 不合理项以红色高亮并给出具体原因；
   - 规则库未覆盖的组合标记为“需技术确认”，不得由 AI 自行推测；
5. 所有模块资料与搭配规则集中保存在独立数据结构中，禁止大量写死 if/else；
6. 未经确认的产品规则在代码中标记为 TODO，不得臆造参数与价格；
7. 提供“导出配置单”按钮，支持导出为 PDF / Excel / 纯文本，
   导出内容含模块清单、数量、用途说明与配置校验结果摘要；
8. 页面白色背景、浅灰边框、简洁工程工具风格；
9. 网页可直接在浏览器运行，不依赖服务器或大型前端框架。

请先搭建可运行的页面框架与示例数据，后续再逐步补充真实模块图片、
SKU、参数与搭配规则。
```
