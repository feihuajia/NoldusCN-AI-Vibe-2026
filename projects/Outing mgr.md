# Outing Manager · 团建活动管理台

> 队伍：大家都是我老师　|　成员：Ariel　|　AI 工具：Codex

## 功能描述

30 人 11 天跨省团建，以前靠 Excel + 微信群来回发文件，信息分散、更新不及时。这个工具把行程、餐饮、住宿、任务全搬到一张网页上，手机打开链接就能看，不用装 App。8 月 9 日活动当天上线，正在实际使用中。

核心功能：

- **逐日行程**：Day1-Day11 卡片，车次、时间线、景点安排
- **住宿导航**：6 家酒店，高德/百度地图一键跳转
- **餐饮全流程**：预点菜单（菜名+价格）、预算、定金、实际消费、包间号
- **火车餐预订**：按车厢座位分布图，谁坐哪、吃什么一目了然
- **任务待办**：按日期和类别（交通/人员/通知）分类跟踪
- **实时状态**：活动进行中、距返程倒计时、云端同步
- **财务管控**：每餐预算 vs 实际消费对比、定金追踪、开票标记、全程花费汇总

**财务模块**：每餐预设预算，活动中实时记录实际消费，超支自动标红提醒；已付定金逐笔追踪，避免重复付款或遗漏；需开票餐厅统一标记，活动结束直接拿清单对账开票。

## 核心 Prompt

> 使用 Codex 在终端中多轮迭代开发，以下为代表性提示词片段。

```text
做一个单页面团建活动管理工具，纯前端，部署到 GitHub Pages。
背景：30人11天跨省团建（北京→山西→郑州→北京），
以前用 Excel 管，信息分散不好共享，手机上看也不方便。

页面需要：
1. 顶部活动总览（名称、时间、路线、人数、倒计时）
2. 逐日行程卡片（Day1-11）：交通车次、时间线、住宿、餐饮
3. 每家酒店和餐厅加高德+百度地图导航链接，手机点击能唤起地图
4. 每顿饭记录：餐厅、预点菜单（菜名+价格）、预算、定金、实际消费、包间号
5. 火车餐按车厢座位分布图排列（窗ABC走道D窗），显示乘客和餐食
6. 任务待办按日期和类别（交通/人员/通知）分类，带时间节点

要求：响应式布局手机能看，信息密度高但不乱，Emoji 辅助快速定位。
先搭框架和两天示例数据，确认结构后再补完整行程。
```
